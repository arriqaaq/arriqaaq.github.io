# blog-publish config — arriqaaq.github.io

Generated by the blog-publish skill's project discovery. Edit freely.

## Content location

Posts live in `content/posts/*.md`. Slug = kebab-case filename. Images go
under `static/images/YYYY/MM/` and are referenced as `/images/YYYY/MM/...`.

## Frontmatter schema

See the `blog-voice` skill (`.claude/skills/blog-voice/SKILL.md`) for the
full schema and an example. Required: `title`, `slug`, `type: post`,
`published`, `updated` (ISO strings, quoted), `tags`, `authors` (keys from
`content/authors.yaml`), `featured`, `reading_time` (minutes ≈ words/200).
Optional: `excerpt`, `feature_image`.

## Voice source

Use the project skill `blog-voice` — it defines the three post-type voices,
example posts for each, Islamic writing conventions (including the
no-fabricated-citations rule), and house-style overrides for the humanizer
pass. It outranks blog-publish defaults wherever they conflict.

## Publish flow

Deploy is `.github/workflows/deploy.yml`: **a push to `main` builds and
deploys the live site** (GitHub Pages, artifact flow). Build =
`npm run build` (parses content, generates llms.txt/markdown mirrors,
vite build, pagefind). Always confirm before pushing to `main`.

## Custom syntax

Custom remark directives (handled by `scripts/remark-ghost-cards.ts`):
`::image{src=... width=full|wide}`, `::bookmark{...}`, `::gallery`,
`::embed`, `::callout`, `::toggle`; plus `[[SVG]]`/`[[WIDGET]]` embed
tokens. Unknown directives pass through as text.
